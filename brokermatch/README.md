# brokermatch

Assets for brokermatch.ae tools, loaded from jsDelivr at a fixed commit.

- `vat-ar.js`: Arabic texts for /ar/vat-calculator-uae. It swaps the English embeds of the VAT calculator before the calculator scripts (VatCore, VatWire, registered in Webflow) run.
- `silver-uae/`: data and script for the "Silver rate today in the UAE" page (same setup as the gold page in pedrofintech/lf-site-assets/gold-uae).

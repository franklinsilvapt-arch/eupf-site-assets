# Bankrekening vergelijken (EUPF NL)

Vergelijker van particuliere en zakelijke rekeningen voor /nl/bankrekening-vergelijken.
Fork van de LF comparador-contas (pedrofintech/lf-site-assets@f3fa33b), vertaald naar het Nederlands.

- `rekeningen.js` / `rekeningen.css`: de tool (root `#lf-cb`)
- `dados/rekeningen.json`: alle gegevens, met `src` per waarde (officiele bronnen)
- `dados/make.py`: script dat de JSON genereert (pas waarden hier aan en draai het opnieuw)
- `logos/`: logo's van de banken

Laatst gecontroleerd: 30 oktober 2026.
